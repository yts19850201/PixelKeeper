# PixelKeeper

이미지와 영상을 로컬에서 변환하는 Windows 도구입니다. 파일을 끌어놓거나 선택하고 형식과 화질을 지정하면 파일별 업로드·변환 퍼센트와 진행률 바가 표시됩니다.

## 실행

[PixelKeeper_v3_260928.exe](PixelKeeper_v3_260928.exe)를 실행합니다. 자동으로 열린 로컬 브라우저 화면에서 변환하세요. HTML 파일을 직접 열면 변환 기능이 작동하지 않습니다. 결과는 실행 파일 옆의 `output_260928` 폴더에도 저장됩니다.

## 기능

- WebP, AVIF, MP4, WebM, JPEG, PNG 변환
- 원본과 출력의 가로·세로 해상도 비교
- 자동 모드에서 원본보다 작은 결과 선택, 없으면 원본 보관
- 파일별 진행률, 변환 후 용량·절감률·처리 시간 표시
- 파일을 외부 서버로 전송하지 않고 PC에서 처리

MP4(H.264) 출력은 가로·세로 픽셀이 짝수인 입력을 지원합니다. MP4·WebM 출력은 소리를 제거합니다. WebM을 웹에서 반복하려면 `<video autoplay loop muted playsinline>`으로 표시하세요.

## 소스 구성

- `app_260928.py`: Python 로컬 서버와 FFmpeg 변환 로직
- `index_260928.html`: 사용자 화면
- `PixelKeeper_260928.spec`: PyInstaller 빌드 설정
- `FFmpeg_LICENSE_260928.txt`: 포함된 FFmpeg 라이선스

EXE에는 FFmpeg가 포함되어 있어 별도 설치 없이 실행됩니다. 소스에서 개발하거나 다시 빌드할 때는 Python 3.12, FFmpeg·ffprobe 실행 파일(`runtime` 폴더), PyInstaller가 필요합니다.
