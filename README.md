# PixelKeeper

이미지·영상의 해상도를 유지하며 로컬에서 변환하고 용량을 비교하는 Windows 프로그램입니다.

## 현재 버전

[PixelKeeper_v3.2_260928.exe](PixelKeeper_v3.2_260928.exe)를 실행하세요. 브라우저에 자동으로 열린 로컬 주소에서 파일을 끌어놓거나 선택할 수 있습니다. 업로드와 변환 진행률은 파일별 퍼센트와 진행률 바로 표시됩니다.

자세한 기능, 실행 방법, 소스 구성은 [README_260928.md](README_260928.md)를 참고하세요.

## v3.2 업데이트

- GIF 이미지 입력과 GIF 변환 추가
- SVG 이미지 입력 및 정지 이미지 변환 추가
- 변환 결과의 원본 해상도와 애니메이션 유지 여부 확인

## v3.1 업데이트

- 로컬 서버 재실행 시 연결 상태 확인 및 업로드 오류 안내 개선
